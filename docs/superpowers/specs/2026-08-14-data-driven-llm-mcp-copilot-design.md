# 데이터 기반 LLM·MCP Copilot 설계

## 목표

새 운영 데이터와 관리기준을 저장하고, 선택 기간의 이상·연관 변수 변화를 계산한 뒤 NVIDIA LLM이 그 근거만으로 Copilot 설명을 생성한다. 동일 데이터·기간·기준 조합의 설명은 재사용한다.

## 구조

Node 내장 SQLite에 일별 운영값, 관리기준, 분석 결과 캐시를 저장한다. 분석 서비스는 기준 이탈, 기간 변화량, 동시 변화와 선택 기간의 상관계수를 계산해 점검 후보를 순위화한다. LLM은 구조화된 분석 결과만 받아 설명하며 원인을 확정하지 않는다.

같은 분석 서비스는 HTTP API와 읽기 전용 MCP 도구에서 함께 사용한다. MCP 도구는 KPI 요약, 관리기준 조회, 기간 분석 결과 조회를 제공한다.

## 안전·비용 원칙

- NVIDIA 키는 `.env` 또는 환경 변수에서만 읽고 Git에 저장하지 않는다.
- 계산 결과는 LLM 호출 없이 생성한다.
- Copilot 설명은 데이터 버전·기준 버전·조회 기간을 키로 캐시해 동일 조회의 LLM 호출을 막는다.
- 근거가 부족하면 단일 원인을 제시하지 않고 분석 한계를 알린다.
- 원인 후보는 점검 후보이며 실제 원인 확정이 아님을 항상 표시한다.

## 화면 동작

Brief & Copilot 화면은 현재 선택 기간으로 API를 호출한다. 데이터 또는 기준이 변경되면 서버의 버전 값이 바뀌고 해당 캐시는 무효화된다. 새 결과가 있으면 기존 UI의 Copilot 카드 내용만 최신 분석 및 생성 문구로 교체한다.

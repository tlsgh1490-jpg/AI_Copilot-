# Copilot / MCP 구현 상태

## 현재 동작

- 운영 데이터, 관리기준, 관계·가중치, Copilot 분석 캐시를 Node 내장 SQLite로 관리한다.
- Copilot은 선택 기간의 최신 기준값과 데이터로 관리기준 이탈·변화량·관계 방향·상관계수·가중치를 계산해 점검 우선순위를 만든다.
- NVIDIA NIM은 계산 결과만 받아 JSON Brief를 생성한다. 정상 JSON이 아니거나 호출이 실패하면 계산 기반 Brief로 자동 전환한다.
- 화면에는 원인 후보, 영향 KPI, 점검 우선순위가 표시되고, `AI 설명` 또는 `계산 기반 설명`으로 출처가 구분된다.
- MCP 도구로 기간 분석, 운영 데이터/관리기준/관계·가중치 조회 및 변경을 할 수 있다.

## 원본 데이터와 원가 계산

- 사용자가 복원한 공정·단가 원본 파일과 기존 원가 계산식은 수정하지 않았다.
- 정적 `_analysis_work/analysis_data.json`은 기존 화면 호환용이다. 시나리오 ID만으로 특정 원인을 단정하지 않으며, 실제 Brief는 조회 시점의 서버 분석으로 생성한다.

## 이후 연결할 항목

1. 실제 설비·업무 시스템에서 새 데이터가 들어오면 `POST /api/observations`에 연결한다.
2. 현재 정적 데이터를 직접 쓰는 표·KPI·그래프는 차례로 DB 조회 API로 전환한다.
3. 현장 검증이 끝난 변수 관계와 가중치만 기준관리에서 등록한다.
